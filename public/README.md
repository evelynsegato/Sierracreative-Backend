# Sierra Creative

Site desenvolvido para a Sierra Creative, com foco na apresentação de serviços de produção de vídeos e registro de eventos.

## Sobre o projeto

A Sierra Creative é uma proposta de empresa voltada para produção audiovisual, oferecendo serviços de Videomaker e Storymaker.

O site foi desenvolvido para apresentar a empresa, seus serviços, trabalhos realizados e disponibilizar uma forma de contato para possíveis clientes.

## Funcionalidades

- Página inicial com apresentação da Sierra Creative
- Página "Sobre" com informações sobre a empresa
- Página de serviços com carrossel entre Storymaker e Videomaker
- Página de portfólio com vídeos separados por categorias
- Página de contato com formulário
- Validação do campo de telefone
- Navegação entre todas as páginas
- Indicação da página atual no menu
- Layout responsivo para diferentes tamanhos de tela
- Efeitos de hover e interação nos elementos
